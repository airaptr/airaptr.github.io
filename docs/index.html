VS Code and other assistants

Any assistant that supports MCP can connect to Raptr.

Setup details
  • Agent Builder: https://airaptr-api.azurewebsites.net/mcp
  • Agent Finder: https://airaptr-api.azurewebsites.net/finder/mcp
  • World Check: https://airaptr-api.azurewebsites.net/world/mcp
  • Domains: https://airaptr-api.azurewebsites.net/domains/mcp
  • Name Finder: https://airaptr-api.azurewebsites.net/names/mcp
  • AI agents can pay per request (x402, USDC, no account): GET /x402/world and POST /x402/domains/register?domain=NAME. Details in llms.txt.
  • Claude and other assistants: add a custom connector with one of the addresses above. No sign-in needed.
  • Claude Code: /plugin marketplace add kody-w/airaptr then /plugin install raptr-agent-builder@rapp
  • ChatGPT developer mode: Settings, then Plugins, then Create custom MCP server with an address above.
