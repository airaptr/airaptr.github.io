Install the free version (Claude Code on a Mac)

Add this to ~/.claude/settings.json, using the folder where you put Pickbox:

git clone https://github.com/airaptr/pickbox ~/pickbox

{"hooks": {"PreToolUse": [{"matcher": "AskUserQuestion", "hooks": [
  {"type": "command", "command": "python3 ~/pickbox/scripts/pickbox_hook.py", "timeout": 3600}]}]}}

Start a new Claude Code chat. When Claude asks you something, the pick list opens. Anywhere a box cannot open, the normal question appears in the terminal.
