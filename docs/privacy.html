Privacy policy

Effective October 4, 2026. Covers Raptr Agent Builder, Raptr Agent Finder and DOGG World Check.

These ChatGPT apps are run by Wildhaven Homes LLC. This policy covers what happens to information the app receives.

What the app receives

Only what ChatGPT sends to the app's tools: a search phrase, an agent name, an operating system choice, or the text of an agent file to check. The app does not ask for your name, email, location, account or payment details.

What we do with it

We use it only to answer that request, in memory, and then discard it. We do not store it in a database, use it to train models, sell it, or share it, and we do not track you across sessions.

Requests you choose to send

If you ask for something the apps can't do yet and agree to pass the request on, we keep the text of that request, with no name or contact details, to decide what to build next.

Service providers

The app runs on Microsoft Azure. Azure keeps short-lived technical logs, such as request time, status and IP address, which we use only to keep the service running, under the Microsoft privacy statement. These logs do not include what you send to the app. We also count which tool was used and whether it worked, so we know what to improve; those counts never include your words, files or data. Agent searches read the public open agent registry (RAR) on GitHub. Your use of ChatGPT is covered by OpenAI's own privacy policy.

Children

The app is not directed at children under 13.

Changes and contact

We will post any changes on this page with a new date. Questions: open an issue.
