# Raptr brand

## Promise
**AI agents anyone can use.** Describe a task in the assistant you already use; Raptr builds the agent, checks it, and runs it on your own data. Nothing to install.

## Names
| Use | Name |
|---|---|
| Brand | **Raptr** (the AI: **AI Raptr**) |
| Domain and handle | **airaptr.com**, `airaptr` everywhere (GitHub, npm, PyPI, Smithery) |
| Apps | Raptr Agent Builder, Raptr Agent Finder, Raptr Names, Raptr Domains, DOGG World Check |
| Run agents on your own computer | Brainstem (free; always the optional last step) |
| Company | Wildhaven Homes LLC |

Never use the name "RAPP" in anything Wildhaven publishes. The open, MIT-licensed pieces (the agent format, RAR, DOGG, the Brainstem) are fine to use and name.

## Voice
- Plain business words. Say what it does for the person.
- Lead with using it now; installing comes last.
- No hype verbs, no em-dashes.
- Honest about limits.
